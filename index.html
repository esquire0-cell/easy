설명서

처음 쓰실 때

내려받기부터 실행까지

  1. 위의 내려받기를 눌러 EasyTest-…-win64.zip을 받습니다. 늘 가장 새 버전이 받아집니다.
  2. 압축을 풀기 전에 zip 파일을 오른쪽 클릭 → 속성 → 차단 해제에 체크하고 확인. 바로 아래에서 그림으로 보여 드립니다.
  3. 이제 압축을 풉니다. 이지테 폴더가 나옵니다.
  4. 그 폴더를 원하는 자리에 통째로 둡니다. 문서 폴더도 좋고 바탕화면도 좋습니다.
  5. 폴더 안의 이지테.exe를 실행합니다. 자주 쓰시려면 이 파일에 바로가기를 만들어 두세요.

압축을 풀기 전에 — 차단 해제

이 한 걸음이면 파란 경고창이 아예 안 뜹니다. 인터넷에서 받은 파일에는 윈도우가 ‘딴 데서 온 것’이라는 표식을 붙여 두는데, 압축을 풀면 그 표식이 안의 파일에까지 옮아붙습니다. 풀기 전에 zip 하나만 떼어 두면 한 번에 끝납니다.

그냥 푸셨다면 — 파란 경고창

차단 해제를 깜빡하고 압축을 푸셨어도 프로그램은 그대로 쓸 수 있습니다. “Windows의 PC 보호” 창이 뜨면 추가 정보를 누르고 실행을 누르세요. 개인이 만든 프로그램이라 마이크로소프트에 값을 내고 받는 서명이 없어서 그렇습니다. 백신이 잠시 잡아 두는 일도 있습니다.

이 경고는 맨 처음 한 번뿐입니다. 뒤에 새 버전이 나와 프로그램이 스스로 업데이트할 때는 뜨지 않습니다 — 브라우저를 거치지 않고 받아서 표식이 안 붙습니다.

한글(HWP)이 깔려 있어야 합니다

이지테는 한글 프로그램을 직접 부려서 문서를 씁니다. 그래서 한글이 없는 컴퓨터에서는 문제지를 만들지 못합니다. 만드는 동안 한글 창이 저절로 떴다 닫히는데 정상입니다 — 그동안은 손대지 마세요.

API 키는 두 곳에서 받아 넣습니다

문항을 만드는 것은 AI입니다. 이지테는 구글 AI 스튜디오와 NVIDIA NIM 두 곳을 씁니다. 둘 다 무료로 키를 받을 수 있고, 설정 › API 키 탭에 각각 넣으면 됩니다. 넣은 키는 그 컴퓨터에만 저장되고 프로그램에는 아무 키도 들어 있지 않습니다.

  • 구글 AI 스튜디오 · 1순위 — 문항을 짓고 자료를 읽는 주력입니다. 빠릅니다.
  • NVIDIA NIM · 2순위 — 구글 한도가 차거나 서버가 답이 없을 때 대신 받습니다. 키는 nvapi- 로 시작합니다. 설정 화면의 [NVIDIA 키 발급받기] · [발급 가이드] 단추가 받는 자리와 순서를 짚어 드립니다.

하나만 넣어도 돌아가기는 합니다. 다만 정답 검산은 서로 다른 두 곳의 모델이 같은 문항을 풀어 견주는 것이라, 한 곳만 넣으면 모든 문항에 ‘한 모델만 풀었습니다’가 붙습니다. 두 개 다 넣으시는 편이 좋습니다.

만든 파일은 어디에 저장되나

따로 정하지 않으면 올린 양식 파일이 있는 폴더에 저장됩니다. 지금 어디에 저장되는지는 설정 화면에서 경로로 보여 드립니다. 파일 이름에는 만든 날짜와 시각이 붙습니다.

공통국어_20260818_1930.hwp · 공통국어_20260818_1930_정답해설.hwp

이지메이커 — 없던 문항을 만듭니다

  1. 학교 양식 한글 파일을 끌어다 놓습니다. 올해 원안지 양식이면 됩니다.
  2. 참고 자료를 올립니다. 교과서·지난 시험지·문제집을 PDF나 사진으로 넣고, 쓸 쪽 범위를 정합니다.
  3. 과목과 문항 수·유형·배점을 정합니다. 객관식과 논술형을 섞을 수 있습니다.
  4. 만들기를 누르고 기다립니다. 끝나면 문제지와 정답해설지가 같이 나옵니다.

스스로 검산합니다

만든 문항은 서로 다른 AI 두 개가 풀어 봅니다. 답이 갈리거나 못 푸는 문항은 ‘확인 필요’로 표시해 둡니다. 그림이 든 문항처럼 AI가 원래 못 푸는 것도 솔직히 그렇다고 적습니다.

검산이 안 되는 문항이 있습니다 — 그 몫은 선생님이

무료로 받는 API에는 그림을 못 보는 모델이 섞여 있습니다. 글은 읽어도 이미지는 아예 받지 못하는 모델이라, 그림·도형·그래프·사진을 봐야 풀리는 문항은 검산 자체가 돌지 않습니다. 표를 그림으로 오려 붙인 문항도 마찬가지입니다.

이런 문항에는 프로그램이 ‘그림을 봐야 푸는 문항이라 정답을 만들지 못했습니다’라고 적어 둡니다. 정답이 비어 있거나 이 말이 붙은 문항은 선생님이 직접 풀어 정답과 배점을 확인해 주세요. 검산을 통과했다는 표시가 없는 것이지, 문항이 틀렸다는 뜻은 아닙니다.

그림이 많은 과목(수학·과학·미술 등)일수록 이렇게 남는 문항이 많습니다. 정답해설지를 그대로 배부하기 전에 꼭 한 번 훑어 주세요.

이지폼 — 있는 시험지를 양식에 옮깁니다

종이로만 있는 기출, 남이 준 PDF, 찍어 온 사진을 학교 양식의 한글 파일로 바꿉니다. 새로 만드는 것이 아니라 그대로 옮겨 적는 쪽입니다.

  • 지문과 <보기> 상자를 원본에서 오려 옵니다. 긴 지문이 잘리지 않습니다.
  • 표·그림은 원본에서 떠서 넣습니다.
  • 밑줄·빈칸·㉠㉡ 표시도 원본을 보고 되살립니다.
  • 수식은 한글 수식 개체로 넣습니다. 글자로 인쇄되지 않습니다.

쓰실 쪽 범위를 정해 주시면 그 안만 읽습니다. 옮긴 문항에도 정답해설을 붙일 수 있습니다.

이지커스텀 — 수업용 학습지

시험지와 달리 양식을 올리지 않습니다. 프로그램 안에 두 가지가 들어 있어 고르기만 하면 됩니다. 오늘 나간 진도로 만들어 수업이 끝난 뒤 학생 확인용으로 바로 쓰시라고 만든 도구입니다.

  • 형성평가지 — 수업 끝에 오늘 배운 것이 남았는지 확인하는 용. 차시 마무리 10분에 풀리기 좋은 분량으로 나옵니다.
  • 자기주도학습지 — 학생이 혼자 풀며 정리하는 용. 과제나 보충·방과후 자료로 내주기 좋습니다.

쓰는 차례는 간단합니다. 양식을 고르고 → 교과서나 수업 자료를 올리고 → 문항 수를 정하면 끝입니다. 정답해설도 같이 붙일 수 있어, 학생이 스스로 맞춰 보게 나눠 주셔도 됩니다.

학교 로고와 학교 정보가 양식에 저절로 들어갑니다

설정 › 학교 정보에 한 번 넣어 두시면 두 양식 모두의 머리표에 자동으로 채워집니다. 학습지를 만들 때마다 로고를 붙이거나 학교 이름을 치실 필요가 없습니다.

  • 학교 로고 — 설정에서 그림(PNG·JPG) 파일을 고르면 머리표 자리에 그림으로 앉습니다. 크게 만든 그림일수록 인쇄가 또렷합니다. 넣지 않으면 그 칸은 빈 채로 나옵니다.
  • 학교명 — 한 해 내내 안 바뀌는 값이라 한 번만 적으면 됩니다.
  • 과목명 — 설정에 적은 것이 기본값이고, 만들 때 과목을 따로 적으면 그쪽이 우선합니다.
  • 단원은 설정이 아니라 만들 때마다 화면에 적은 것이 그대로 들어갑니다.

새 버전이 나오면 알려 드립니다

프로그램을 켜고 몇 초 뒤에 조용히 확인합니다. 새 버전이 있으면 무엇이 바뀌었는지와 받을 크기를 보여 드리고, [지금 업데이트]를 누르면 그 자리에서 받아 갱신합니다. 프로그램이 한 번 꺼졌다 다시 켜집니다.

  • 설정과 키, 지난 기록은 그대로 남습니다. 다시 넣지 않으셔도 됩니다.
  • 업데이트 중에는 만들던 문서를 먼저 저장해 주세요.
  • 인터넷이 안 되면 아무 말 없이 넘어갑니다. 프로그램은 그대로 켜집니다.
  • 직접 확인하시려면 설정 › 업데이트 확인을 누르세요.

설치

exe 파일 하나만 옮기면 켜지지 않습니다

압축을 풀면 이지테.exe 옆에 _internal 폴더가 있습니다. 프로그램의 알맹이가 다 그 안에 들어 있어서, exe만 바탕화면으로 꺼내 놓으면 실행되지 않습니다.

폴더째 옮기고, 바로가기를 만들어 쓰세요.

첫 실행

압축을 풀기 전에 ‘차단 해제’를 하면 안 뜹니다

받은 zip 파일에 오른쪽 클릭 → 속성 → 차단 해제 → 확인을 하고 압축을 푸시면 파란 경고창이 아예 안 뜹니다. 순서가 중요합니다 — 푼 뒤에는 파일마다 따로 해 주셔야 합니다. (설명서 › 설치에 그림으로 짚어 두었습니다.)

깜빡하고 그냥 푸셨어도 괜찮습니다. “Windows의 PC 보호”가 뜨면 추가 정보 → 실행을 누르세요. 코드 서명을 받지 않은 개인 제작 프로그램이라 뜨는 것으로, 프로그램에 문제가 있다는 뜻은 아닙니다. 맨 처음 한 번뿐이고, 뒤에 스스로 업데이트할 때는 뜨지 않습니다.

필요한 프로그램

한글(HWP)이 깔려 있어야 합니다

이지테는 한글을 직접 부려서 문서를 만듭니다. 한글이 없으면 문제지가 나오지 않습니다. 작업 중 한글 창이 저절로 떴다 닫히는 것은 정상이니 그동안 손대지 마세요.

API 키

키는 두 개, 각자 발급받아 넣습니다

프로그램에는 어떤 키도 들어 있지 않습니다. 구글 AI 스튜디오와 NVIDIA NIM에서 무료 키를 받아 설정 › API 키에 넣으세요. 넣은 키는 그 컴퓨터에만 저장됩니다.

하나만 넣어도 문제지는 나오지만, 정답 검산은 두 곳이 있어야 제대로 됩니다. 한 곳만 넣으면 모든 문항에 ‘한 모델만 풀었습니다’가 붙습니다.

검토

나온 문항은 반드시 사람이 봐야 합니다

AI가 만든 문항에는 틀린 곳이 섞일 수 있습니다. 옮겨 적은 문항도 원본과 글자가 어긋날 수 있어, 프로그램이 ‘원본과 견줘 확인하세요’라고 함께 적어 드립니다.

시험에 그대로 쓰기 전에 꼭 검토해 주세요. 확인이 필요한 문항은 프로그램이 따로 표시해 둡니다.
